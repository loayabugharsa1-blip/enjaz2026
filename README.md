# إنجاز — Enjaz Advertising Platform

منصة رقمية متكاملة لشركة إنجاز للدعاية والإعلان — تجمع بين موقع إلكتروني تفاعلي للعملاء ولوحة تحكم شاملة للإدارة.

**الموقع:** [injaz-phi.vercel.app](https://injaz-phi.vercel.app)

---

## المميزات

### الموقع العام
- عرض الخدمات (5 أقسام رئيسية، 104 خدمة)
- طلب خدمات أونلاين مع حساب السعر التلقائي
- تتبع الطلبات برمز `ENJ-XXXXX`
- آراء العملاء ومعرض أعمال
- حاسبة أسعار ذكية
- توافق كامل مع RTL/عربي

### لوحة التحكم (Dashboard)
- **التقارير:** إحصائيات يومية، رسم بياني 7 أيام، توزيع الحالات
- **نقطة البيع (POS):** سلة مشتريات، اختيار خدمات، طباعة فاتورة
- **الطلبات:** بحث، تصفية، تحديث حالة، واتساب، تصدير CSV
- **المخزون:** إدارة الأصناف مع ربط الخدمات
- **الخدمات:** إضافة/تعديل/حذف الخدمات والفئات
- **العملاء (CRM):** سجل العملاء وإجمالي المشتريات
- **المستخدمين:** صلاحيات (admin/employee/staff)
- **سجل الحركات:** تدقيق كامل لكل الإجراءات
- **النسخ الاحتياطي:** تصدير/استيراد جميع البيانات

## الأمان

- 🔒 **توقيع الجلسات:** جميع جلسات المستخدمين موقعة لمنع التلاعب
- 🚦 **تحديد معدل الطلبات (Rate Limiting):** على API الطلبات العامة
- 🛡️ **رؤوس أمنية:** HSTS, X-Frame-Options, X-Content-Type-Options
- 🔐 **تشفير كلمات المرور:** bcryptjs (10 rounds)
- 📋 **سجل تدقيق:** تتبع كل إجراءات المستخدمين
- ☁️ **مزامنة تلقائية:** المستخدمون يُزامنون مع Supabase

## التطوير المحلي

```bash
# 1. تثبيت الاعتماديات
npm install

# 2. نسخ ملف البيئة
cp .env.example .env.local
# ثم املأ مفاتيح Supabase من لوحة التحكم

# 3. تشغيل التطوير
npm run dev
```

---

## النشر

النشر التلقائي على Vercel:

```bash
vercel --prod
```

متغيرات البيئة المطلوبة في Vercel:
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY` (صلاحية كاملة للقاعدة)
- `SESSION_SECRET` (لتوقيع جلسات المستخدمين)
